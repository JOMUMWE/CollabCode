# CollabCode
 A Real-Time Collaborative Code Editor
## About the Project

CollabCode is a real-time collaborative code editor designed to allow multiple users to write, edit, and debug code together seamlessly. It supports syntax highlighting, live updates, and a user-friendly interface to enhance productivity and teamwork.

### Features
- **Real-Time Collaboration**: See changes as they happen.
- **Syntax Highlighting**: Supports multiple programming languages.
- **User Authentication**: Secure login for users.
- **Session Management**: Create and join collaborative sessions.
- **Cross-Platform**: Works on any modern browser.

## Getting Started

Follow these instructions to set up the project locally.

### Prerequisites
- Node.js (v14 or higher)
- npm (v6 or higher)
- Git

### Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/JOMUMWE/CollabCode.git
    cd CollabCode
    ```

2. Install dependencies:
    ```bash
    npm install
    ```

3. Create a `.env` file in the root directory and configure the following variables:
    ```
    PORT=3000
    DATABASE_URL=your_database_url
    JWT_SECRET=your_secret_key
    ```

4. Start the development server:
    ```bash
    npm start
    ```

5. Open your browser and navigate to `http://localhost:5173`.

## Usage

1. Sign up or log in to your account.
2. Create a new session or join an existing one using a session ID.
3. Start coding collaboratively in real-time.
